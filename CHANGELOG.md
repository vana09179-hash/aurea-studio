# Що нового

## Наступна версія
- Експорт у .pptx: Morph стає справжнім «Морфінгом» PowerPoint, анімації — найближчими стандартними ефектами (виринання, масштаб, виліт, поява смугами, по словах і по буквах)
- Картинки з режимом накладання «screen» експортуються без чорного тла
- Після експорту .pptx — список шрифтів презентації з посиланнями для встановлення
- Після аварійного закриття програма сама перезапускається й відкриває роботу з автозбереження
- При будь-якій неочікуваній помилці робота одразу зберігається
- Автоматичні тести на кожен push: усі сценарії редактора, перевірка .pptx у LibreOffice
- macOS: ad-hoc підпис — програма більше не позначається як «пошкоджена»
