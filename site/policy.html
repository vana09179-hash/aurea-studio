Code signing policy

Aurea Studio is free, open-source software (MIT license). Release binaries are built from the public source code at github.com/vana09179-hash/aurea-studio by GitHub Actions (build.yml). Nothing is built or signed on a personal computer.

Status: an application for free Windows code signing through SignPath Foundation has been prepared. Until it is approved, Windows builds are unsigned and macOS builds carry only an ad-hoc signature.

Конфіденційність

Aurea Studio не збирає статистику, не має реклами й не надсилає ваші презентації нікуди. Файли зберігаються лише на вашому комп’ютері.

Як видалити

Програма нічого не змінює в системі й не додає служб чи автозапуску.

Windows

Видаліть файл AureaStudio-…-portable.exe. Налаштування й автозбереження лежать у %APPDATA%\Aurea Studio — видаліть цю папку, щоб прибрати їх теж.

macOS

Перетягніть «Aurea Studio» з «Програм» у Кошик. Налаштування: ~/Library/Application Support/Aurea Studio.

Linux

Видаліть розпаковану папку AureaStudio-…-linux-x64. Налаштування: ~/.config/Aurea Studio.

Ваші файли .aurea, PDF і .pptx залишаються там, куди ви їх зберегли.
