# Як долучитися

Дякуємо, що хочете допомогти! Найпростіше почати з [Issues](https://github.com/vana09179-hash/aurea-studio/issues).

## Запуск

```bash
npm ci
npm start
```

## Де що лежить

| Файл | Що всередині |
|---|---|
| `main.js` | Головний процес Electron: вікна, файли, експорт PDF, ШІ |
| `preload.js` | Міст між вікном і головним процесом (`window.aurea`) |
| `src/player.js` | Рендер слайдів і всі анімації (спільний для редактора, показу й експорту HTML) |
| `src/app.js` | Редактор: панелі, полотно, експорт і імпорт .pptx |
| `src/v5.js` | Таблиці, компоненти, автомакет, історія версій |
| `src/templates.js` | Шаблони |

## Перевірка перед pull request

```bash
npx electron . --shots=out --skip=40,41,42
python tools/check-run.py out
```

Перша команда проходить усі сценарії редактора й зберігає скріншоти в `out/`, друга перевіряє, що немає помилок JavaScript і що експортовані файли коректні. Те саме автоматично запускається на GitHub для кожного pull request.

## Добрі перші завдання

- Переклад інтерфейсу іншими мовами
- Нові шаблони (`src/templates.js`)
- Нові анімації (`src/player.js`, функція `playIn`)

## Стиль

- Тексти інтерфейсу українською, короткі й зрозумілі.
- Без нових залежностей без потреби — програма має запускатися швидко й займати мало пам’яті.
